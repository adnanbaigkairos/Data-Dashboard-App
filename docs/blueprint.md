# **App Name**: Data Canvas

## Core Features:

- CSV Upload: Upload data from a CSV file.
- Column Selection: Select columns from the uploaded data for plotting via dropdown menus.
- Chart Type Selection: Choose chart type from a selection including Line Plot, Bar Chart, Pie Chart, Map Plot, Histogram, Density Plot, and Count Plot.
- Plot Display: Display generated plots on a dashboard area.
- Interactive Plots: Drag and resize plots to rearrange the dashboard layout. Each plot has zoom, hover, tooltip, and filter interactions.
- Theme Switcher: Toggle between Light Mode and Dark Mode themes using a switch.
- Dashboard Export: Download the entire dashboard as a PDF, Image, or HTML file.

## Style Guidelines:

- Primary color: Deep turquoise (#45B8AC) evoking a sense of data clarity and innovation.
- Background color: Dark navy (#242B3F) creates a professional feel.
- Accent color: Muted blue-purple (#755595) for interactive elements such as tooltips and buttons.
- Clean and modern sans-serif font for clear data presentation.
- Flexible grid layout to allow users to rearrange plots as needed.
- Smooth transitions when plots are generated or rearranged.
